05 · TRUST BOUNDARY

远程模型只看必要文本，永远看不到课堂媒体。

允许发送

人工去标识后的教学目标、必要画像摘要、相关历史、Skill 摘要和本轮学生回答；系统会再遮盖部分常见标识符。

永不发送

真实视频、帧、音频、字幕全文、OCR、逐样本预测、本机路径和 API Key。

当前未建立

自由文本诊断准确率、专家盲评质量、真实学习效果和部署准确率。

会话处理

自动遮盖不能替代人工去标识。页面仅连接本机服务，浏览器不保存教学会话，并明确标记在线模型或 fallback。
