# Private DIPSER artifacts

Everything below this directory is local controlled research data unless it has been explicitly converted to an aggregate report under `artifacts/public/` and passed `tsm release-audit`.

Do not commit or publish `archive_cache`, `dataset_manifest.json`, `features.json`, row-level predictions, participant/sample IDs, timestamps, labels, or local paths. Recommended permissions are directory `0700` and file `0600`.
