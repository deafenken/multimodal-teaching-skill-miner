# Public aggregate artifacts

Only aggregate reports intended for the public boundary belong here. Every file must exclude raw media, row-level labels/predictions/features, sample or participant IDs, source paths, and secrets, then pass `tsm release-audit` before publication. Passing that audit is not a proof of anonymity or non-reidentifiability; rare aggregate cells, free text, and dataset-specific linkage risk still require human disclosure review.

`dipser_0_9_aggregate_summary.json` was generated from the private hierarchical report by `tsm export-public-dipser`; its source SHA-256 is embedded for traceability.

Its `0.902027` Accuracy is a post-selected, offline full-session transductive development estimate. It is not deployment Accuracy, real-time single-learner Accuracy, or a stable cross-session `0.9` result.

`formal_caption_retrieval_receipt.json` is the text-free receipt from the 10/10 MIT OCW official-caption retrieval. It contains official page/caption URLs, hashes, media durations, cue counts, and conservative first-to-last-cue timeline coverage, but no caption text or classroom media. `formal_empirical_ready=true` in this receipt establishes transcript provenance/completeness only; it does not establish label validity, multimodal gain, learning effectiveness, or deployment Accuracy.

`full_video_validation_receipt.json` is the content-free receipt for the 10 complete MIT OCW media files used by the private whole-timeline multimodal run. It records 1,038,813,006 total bytes, 26,656.829 seconds, per-video local SHA-256 values, durations, and audio/video stream counts, but no media, captions, frames, OCR, embeddings, events, or local file paths. The local hashes detect mutation after download; they do not independently authenticate upstream publisher bytes because no publisher media hashes were pinned. This receipt proves neither event recognition accuracy nor multimodal, learner, or deployment benefit.

`full_multimodal_validation_receipt.json` commits to the private semantic manifest, audit, model-weight manifest, and per-lecture semantic result set while exposing only aggregate coverage/counts and explicit evidence-status flags. It omits media, caption/OCR text, frames, embedding values, lecture identifiers, per-lecture records, identities, and local paths.

`multimodal_ablation_receipt.json` records the four-arm paired design and aggregate internal rubric/output-count results, with SHA-256 commitments to the private inputs. Its current transcript-only / +audio / +visual / full means are 95.37/95.37/95.30/95.32 under the seven-dimension internal rubric. Only `method_fidelity` re-derives observed-step claims from cited evidence; the other six dimensions are saturated at a population standard deviation of 0.000 across the ten demo Skills. These values are not Accuracy or independently judged Skill quality; the receipt explicitly leaves recognition, causal gain, deployment, and learner-effect claims unestablished.

`teachobs_annotation_receipt.json` commits to the commit-pinned TeachObs v0.1 audit without source URLs, lesson IDs, transcript text, media, or scene labels. It reports the 30-lesson/5,158-scene/39-code aggregate and the source-reported seven-coder protocol, while explicitly recording that individual coder files and independently recomputed reliability are unavailable.

`teachobs_text_benchmark_receipt.json` contains the aggregate official 23/7 transcript-only benchmark. Micro/Macro-F1 are the principal results; Hamming accuracy is not presented alone as general “Accuracy.” The public test labels predated this implementation, so the receipt is exploratory rather than an external lockbox.

`teachobs_caption_receipt.json` is the content-free result of the safe subtitle retrieval and timeline audit. It currently reports 23/30 lessons and 34 tracks audited, mean timeline-span coverage 0.985841, and 7 lessons still pending. Creator-provided versus automatic is the platform track category, not independently verified human authorship; normalized overlap is not WER or caption accuracy. Formal caption completeness, content accuracy, and WER therefore remain false.

`teachobs_asr_receipt.json` is the aggregate/hash-only receipt for the offline GPU ASR handoff. Its generated aggregate and `handoff_status` are the authority for current progress: the pending receipt is recomputed from the current media/caption/job inputs, and the completed form can only be emitted by the strict result importer. The private workflow binds each selected lesson media hash/duration to an exact model revision, model-tree hash, decoding contract and CUDA runtime, then prefers audited platform captions over ASR fallback. ASR is never classified as an official caption; without an independent human reference sample, content accuracy and WER remain false even after a technically valid import.

`teachobs_transcript_materialization_receipt.json` is the text-free aggregate receipt for the fixed 29-lesson/4,945-scene paper profile. It binds the selected creator-provided, automatic-caption, and audited-ASR source tiers plus deterministic endpoint projection counts, but includes no transcript text, lesson/scene IDs, URLs, paths, labels, or predictions. It establishes input provenance and timing projection only; WER and content accuracy remain false.

`teachobs_human_annotation_paper_track1_20260723_receipt.json` describes the current 29-lesson/4,945-scene empty A/B blind-assignment package only. The upstream 39 code definitions are blank, so no operational codebook, real annotator rows, kappa, or adjudication is claimed. A complete external 39/39 expert codebook and all private media must be bound before annotation can start; `human_completion=false` is intentional. The older 30-lesson receipt is retained privately as history and is not part of this public set.

`teachobs_multimodal_benchmark_receipt.json` is the aggregate-only receipt produced by the exact paper-profile four-arm runner. It binds the current 29-lesson transcript materialization, 4,945-scene feature manifest, five-fold training-lesson OOF selection, private result, and prediction-identical frozen v2 bundle. The revised test Micro-F1 values for transcript/+audio/+visual/full are 0.594496/0.604708/0.548328/0.543812; full improves Macro-F1 and visual Macro-F1 but reduces Micro-F1 and Hamming accuracy. The fixed-threshold first test run was observed before this revision, so the receipt explicitly remains post-test exploratory and cannot establish confirmatory multimodal gain, an external lockbox, deployment Accuracy, or learner effectiveness.

`teachobs_new_site_paper_track1_lockbox_preregistration_20260723_draft.json` is a no-outcome, fail-closed schema 1.2 / protocol v2 draft for a future new-site four-arm confirmation. It validates one bundle manifest, all four matching arm manifests and companion `arrays.npz` files, and binds each arm's exact 39-label `model_thresholds` array hash into one path-free transitive artifact-set fingerprint. It also freezes the same-sample primary contrast, 39-label Macro-F1, classroom/session cluster, 2,000 paired bootstrap replicates, coverage, prospective and one-time requirements. The model artifact set is complete, but external registration/signature and target execution evidence are absent, so execution readiness and every established claim remain false. The older scalar-threshold draft is retained privately and is not part of this public set.
